## 阅读器功能

- **目录**：512 章 + 作者附言，支持跳转、已读标记（灰）、当前章节高亮
- **书签**：手动设置 / 改设 / 删除，下次打开一键回到书签位置
- **听书**：基于 Web Speech API
  - 播放 / 暂停 / 停止、上一段 / 下一段
  - 语速 0.5×–2.5×、系统中文音色选择
  - 10 / 20 / 30 / 60 分钟定时关闭
  - 当前段高亮 + 自动滚动、跨章节自动续读
  - 点击正文任意段落，从该处开始朗读
  - 空格键播放 / 暂停
- **夜读模式**、**顶部阅读进度条**、**手机端适配**
- **边看边读**：右侧展开红果官方播放器，左边读文字右边看剧
  - 内嵌红果短剧官网播放页（官方源，非转载）
  - 集数导航（共 103 集）、自动跟随章节对照集数、手动可覆盖
  - 桌面左右分栏，手机全屏视频层
- **剧集对照**：把小说章节和红果短剧《御兽学院》的集数对应起来
  - 看到某一集时填集数点「记下」，中间的章节自动线性插值估算
  - 每章标题旁显示「第 N 集」（精确）或「≈ 第 N 集」（推算）
  - 支持「跳到该集起始章」、标注列表管理、导出 / 导入 JSON

阅读进度、书签、听书设置、剧集对照均存于浏览器 `localStorage`，不上传任何数据。
